# Pé na Areia · Praia do Morro

Site de apresentação do apartamento de temporada **Pé na Areia**, em frente ao Quiosque 12 na Praia do Morro, Guarapari (ES).

Reservas: https://airbnb.com.br/h/leila201

## Estrutura

- `index.html` — a página completa (HTML, CSS e JS em um só arquivo)
- `img/` — fotos do apartamento
- `beach/` — fotos da praia (créditos no rodapé do site, Wikimedia Commons)
- `tourds/`, `tourms/` — quadros da animação de abertura (desktop e celular)
- `video/` — filme do apartamento e imagem de capa
- `audio/` — trilhas do player

## Publicar com GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch `main`, pasta `/ (root)`.
O site fica em `https://<seu-usuario>.github.io/<nome-do-repo>/`.
